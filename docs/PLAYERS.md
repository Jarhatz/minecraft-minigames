# For players — how to join

1. **Get Minecraft Java Edition 1.20.1.**

2. **Install Forge 1.20.1** (`47.4.10` or a compatible 1.20.1 build) and create a
   1.20.1 Forge profile in your launcher. https://files.minecraftforge.net

3. **Install the required mods** (only if the server runs them — ask the host).
   Put these `.jar`s in your client `mods/` folder. They must match the server's
   versions:
   - **Upgrader** (Upgrade Items) — the gambler item.
   - **YYZS Backpack** — portable storage.
   - *(optional)* Simple Voice Chat, Realistic Nametag — if the server uses them.

   See `server/mods.md` for versions and sources. If the server has these mods,
   you **must** have them too or you'll be rejected at login.

4. **Make sure you're whitelisted.** These servers usually run a whitelist — give
   the host your exact username.

5. **Join** the server's address (host + port, default `25565`).

6. In-game, an operator starts a game. Watch chat / the bossbars / the sidebar
   for instructions. For Circle Hunt your target compass lives in hotbar slot 9.

That's it — no client config needed beyond matching mods. If you can't connect,
it's almost always a Forge version or mod-list mismatch with the server.
